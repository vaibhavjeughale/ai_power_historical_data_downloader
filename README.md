# Market Historical Data Downloader

A full-stack financial market data application for traders, analysts, and algorithmic developers. Allows users to select market instruments (Indices, Equities, Commodities), configure timeframes (intraday minutes to monthly bars), choose custom historical date ranges, fetch real OHLC market data from configured providers, preview candles with an interactive candlestick chart and paginated table, and export formatted multi-sheet Excel (`.xlsx`) and CSV files.

---

## 🌟 Key Features

### 1. Supported Instruments
- **Benchmark Indices:**
  - NIFTY 50 (`^NSEI`, NSE)
  - BANK NIFTY (`^NSEBANK`, NSE)
  - S&P BSE SENSEX (`^BSESN`, BSE)
- **Sectoral & Broad Indices:**
  - FINNIFTY (`NIFTY_FIN_SERVICE.NS`, NSE)
  - MIDCPNIFTY (`NIFTY_MIDCAP_100.NS`, NSE)
- **Individual Equities:**
  - Reliance Industries (`RELIANCE.NS`, NSE)
  - Tata Consultancy Services (`TCS.NS`, NSE)
  - Infosys (`INFY.NS`, NSE)
  - HDFC Bank (`HDFCBANK.NS`, NSE)
  - ICICI Bank (`ICICIBANK.NS`, NSE)
  - Tata Steel (`TATASTEEL.NS`, NSE)
- **Commodities:**
  - Crude Oil WTI Futures (`CL=F`, MCX/NYMEX)
  - Gold Futures (`GC=F`, MCX/COMEX)
  - Gold Mini Futures (`MGC=F`, MCX)
  - Silver Futures (`SI=F`, MCX/COMEX)
- **Custom Instrument Input:** Users can add and download any custom ticker symbol (e.g. `TATAMOTORS.NS`, `AAPL`, `BTC-USD`).

### 2. Timeframe Selection
- **Intraday:** 1 Minute (`1m`), 3 Minutes (`3m`), 5 Minutes (`5m`), 10 Minutes (`10m`), 15 Minutes (`15m`), 30 Minutes (`30m`), 1 Hour (`1h`).
- **Daily & Higher:** 1 Day (`1d`), 1 Week (`1wk`), 1 Month (`1mo`).
- **Provider Capability Engine:** Validates public exchange limits (e.g., 1m is capped at 7 days, 5m at 60 days on public feeds) and offers clear user-friendly guidance.

### 3. Date Range Selection
- Quick presets: Today, Last 7 Days, Last 30 Days, Last 3 Months, Last 6 Months, Last 1 Year, Year-to-Date (YTD), All Available Data.
- Select Year and Select Month dropdowns with automatic date range computation.
- Custom Start Date and End Date inputs with strict forward-looking date prevention.

### 4. Authoritative Data Source Architecture (No Fabrication)
- **MarketDataProvider Adapter Pattern:** Pluggable backend interface `fetchHistoricalData({ instrument, symbol, exchange, timeframe, startDate, endDate })`.
- **Live Provider:** `YahooFinanceProvider` fetching real live market candles from exchange charting APIs.
- **Developer Sandbox Provider:** `MockSandboxProvider` clearly labeled for offline unit testing and automated CI without hitting public rate limits.
- **Strict Data Cleaning Engine:**
  - Chronological sorting
  - Deduplication by timestamp
  - Mathematical integrity checks: `High >= max(Open, Close)` and `Low <= min(Open, Close)`
  - Zero silent candle fabrication.

### 5. Multi-Sheet Professional Excel Export (.xlsx)
- Generated server-side using **ExcelJS**.
- **File Name Format:** `{INSTRUMENT}_{TIMEFRAME}_{START_DATE}_TO_{END_DATE}.xlsx` (e.g. `NIFTY50_5MIN_2025-01-01_TO_2025-12-31.xlsx`).
- **Sheet 1 (`Historical Data`):**
  - Columns: Date, Time, Open, High, Low, Close, Volume, Instrument, Symbol, Exchange, Timeframe.
  - Frozen header row, bold slate styling, auto-adjusted column widths, currency numeric format `#,##0.00`, integer volume `#,##0`.
- **Sheet 2 (`Download Information`):**
  - Download metadata table: Instrument, Symbol, Exchange, Timeframe, Start Date, End Date, Total Records, Data Source, Download Generated At, Period High/Low, Net Change %, and Mathematical Audit Status.

### 6. CSV Download & Data Preview
- RFC 4180 CSV export for direct ingestion into Python (Pandas/NumPy), TradingView, and PineScript.
- Paginated table with search across all columns, sorting by column, and specific date filter.
- Interactive HTML5 Canvas Candlestick & Volume chart with crosshair inspection and area view toggle.
- Range & Volatility breakdown modal (High-Low spread, Average True Candle Range, Boundary Anchor Candles).

### 7. Gemini AI Market Query Assistant
- Natural language query box: *"Download NIFTY 5-minute data for January 2025"*, *"Get BANKNIFTY daily data from 2023 to 2025"*.
- Powered by `gemini-3.8-flash` via `@google/genai` TypeScript SDK on the server backend.
- Extracts instrument, timeframe, and dates into structured JSON.
- Displays an interactive confirmation card for the user before fetching any data.
- AI is strictly constrained to query interpretation; market data is never generated by AI.

## 🚀 Setup & Execution

### Prerequisites
- Node.js >= 20
- npm >= 9

### Environment Variables
Create a `.env` file based on `.env.example`:
```env
# GEMINI_API_KEY: Injected automatically by AI Studio from Secrets panel
GEMINI_API_KEY="your-gemini-api-key"
PORT=3000
```

### Running Locally
```bash
# Install dependencies
npm install

# Start full-stack dev server (Express backend + Vite frontend)
npm run dev
```

Visit `http://localhost:3000` in your browser.

## 📡 API Endpoints

| Method | Endpoint | Description |
|---|---|---|
| `GET` | `/api/instruments` | Returns supported instruments & timeframe options |
| `GET` | `/api/providers` | Lists configured market data providers |
| `POST` | `/api/historical-data` | Fetches, validates, and cleans historical OHLC candles |
| `POST` | `/api/download/excel` | Generates and streams styled 2-sheet `.xlsx` file |
| `POST` | `/api/download/csv` | Streams RFC-4180 `.csv` dataset |
| `POST` | `/api/ai-parse` | Interprets natural language prompt into parameters using Gemini 3.8 Flash |
| `GET` | `/health` | Server health check endpoint |
